## 第一步：购买域名

### 1.1 选择平台（推荐阿里云）

阿里云是国内最大的域名注册商，备案流程也最顺畅。

**阿里云官网**: https://wanwang.aliyun.com/

### 1.2 注册阿里云账号

1. 打开阿里云官网
2. 点击右上角【免费注册】
3. 使用手机号注册
4. 完成实名认证（需要身份证）

### 1.3 选择域名

1. 在阿里云首页搜索框输入想要注册的域名，如：`mywigshop`
2. 选择后缀（推荐）：
   - `.com` - 国际通用，每年约 55-70元
   - `.cn` - 中国域名，每年约 29-40元
   - `.net` - 网络机构，每年约 60-70元

**建议**: 选择 `.cn` 最便宜，`.com` 最通用

### 1.4 购买域名

1. 选择心仪的域名，点击【加入购物车】
2. 选择购买年限（建议1年先试试）
3. 填写域名所有者信息（实名认证会自动填充）
4. 支付费用

**注意事项**:
- 域名必须实名认证后才能使用
- 实名认证通常 1-3 个工作日

## 第二步：ICP备案

**重要**: 所有中国大陆服务器的网站都必须备案！

### 2.1 进入备案系统

1. 登录阿里云
2. 搜索【ICP备案】或访问：https://beian.aliyun.com/
3. 点击【开始备案】

### 2.2 准备材料

| 材料 | 说明 |
|------|------|
| 身份证正反面照片 | 清晰、完整、无遮挡 |
| 手持身份证照片 | 露出五官、身份证信息清晰 |
| 个人手持照片 | 部分地区需要，阿里云APP可拍摄 |
| 域名证书 | 在域名控制台下载 |

### 2.3 填写备案信息

1. **主体信息**：
   - 主体类型：个人
   - 姓名、身份证号、联系方式
   - 通讯地址（精确到门牌号）

2. **网站信息**：
   - 网站名称：如"假发推广平台"、"个人推广网站"
   - 网站备注：如"个人推广分销系统"
   - 前置审批：一般选"无"

### 2.4 提交审核

1. 上传所有材料
2. 使用阿里云APP进行人脸核验
3. 提交备案申请

### 2.5 等待审核

| 阶段 | 时间 | 说明 |
|------|------|------|
| 阿里云初审 | 1个工作日 | 阿里云审核材料 |
| 短信核验 | 即时 | 收到工信部短信，点击链接确认 |
| 管局审核 | 5-20个工作日 | 各省份时间不同 |
| 备案成功 | - | 收到备案号 |

**提示**: 备案期间可以查看进度，有问题会短信通知

## 第三步：域名解析配置

### 3.1 获取服务器信息

备案成功后，联系我们获取：
- 服务器IP地址
- 或CNAME记录值

### 3.2 配置解析

1. 登录阿里云域名控制台
2. 点击域名后的【解析】
3. 添加记录：

**记录类型**: A记录 或 CNAME
**主机记录**: 
- `@` (解析主域名，如 example.com)
- `www` (解析 www.example.com)

**记录值**: 我们提供的服务器地址

### 3.3 等待生效

- DNS解析生效时间：10分钟 - 2小时
- 生效后即可正常访问

## 常见问题

### Q1: 备案需要多久？
**A**: 整个流程大约 10-20 个工作日，各省份不同。

### Q2: 备案收费吗？
**A**: 阿里云备案完全免费！

### Q3: 备案期间能用吗？
**A**: 备案期间网站不能访问，但可以先开发测试。

### Q4: 个人能备案吗？
**A**: 可以！个人备案完全合法，只是网站名称不能用企业相关词汇。

### Q5: 备案后能改网站内容吗？
**A**: 只要不涉及违法内容，正常修改没问题。

### Q6: 域名每年多少钱？
**A**: 
- `.cn` 域名：约 29-40元/年
- `.com` 域名：约 55-70元/年
- 首年通常有优惠
