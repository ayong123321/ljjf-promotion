## 一、先创建本地项目

打开终端（命令行），执行：

```bash
# 创建项目（按提示选择 Yes/Yes/Yes/Yes/Yes/No）
npx create-next-app@latest wig-promotion --typescript --tailwind --app --src-dir

# 进入项目目录
cd wig-promotion
```

创建时的选项：
- TypeScript? → **Yes**
- ESLint? → **Yes**
- Tailwind CSS? → **Yes**
- `src/` directory? → **Yes**
- App Router? → **Yes**
- Turbopack? → **Yes**
- Customize import alias? → **No**

#### 📁 `src/storage/database/supabase-client.ts`（新建文件）

```typescript
import { createClient, SupabaseClient } from '@supabase/supabase-js';

function getSupabaseClient(): SupabaseClient {
  const url = process.env.NEXT_PUBLIC_SUPABASE_URL;
  const anonKey = process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY;

  if (!url || !anonKey) {
    throw new Error('Missing Supabase environment variables');
  }

  return createClient(url, anonKey, {
    auth: {
      autoRefreshToken: false,
      persistSession: false,
    },
  });
}

export { getSupabaseClient };
```

## 七、常见问题

### Q: 提示找不到模块？
A: 确保所有依赖都安装了：`pnpm install`

### Q: 类型错误？
A: 确保安装了 TypeScript 相关依赖

### Q: 样式不生效？
A: 确保 `globals.css` 已正确覆盖
